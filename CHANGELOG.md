# Changelog

All notable changes to this project are documented in this file. The project follows [Semantic Versioning](https://semver.org).

## [0.1.0] - 2026-11-08

First public version.

### Added

- Claude skill that turns one sentence into a finished Scriptable widget
- `PROMPT.md` for ChatGPT, Gemini and other chatbots
- Widget Installer that saves code from the share sheet or clipboard without running it
- Example widgets: Weather, Days Alive, Sunset Score, Star Night, Fresh Air and What to Wear
- Static script checks, run on every pull request
- Release workflow that publishes the skill as a ZIP
